- `klt functional-verification` with `options.sdf` now refuses, before the build, an SDF whose `TIMESCALE` differs from the HDL unit Icarus uses for a retained delay, or whose unit cannot be established. Icarus uses the cell's unit for `IOPATH` and the annotation module's unit for `INTERCONNECT`. A `1ps` file on `1ns` cell models could apply path delays 1000x too large while the report said `annotated: true`. A matching run records the SDF's `TIMESCALE` and the unit its delays were applied in as the additive `environment.sdf.timescale` and `environment.sdf.time_unit` on both the cocotb and Verilog-bench paths (#7983).
