# `tests/corpus/legalize/` — issue #784's legalizer-spike fixtures

Machine-generated, like `tests/corpus/place_and_route/gcd.gds.gz` (see
`../README.md`'s "Machine-generated macro-scale fixture" section) — but a
different granularity: a **pre-legalization** ("global placement", GP) DEF
checkpoint plus OpenROAD's own **legalized** DEF on that identical input,
for two designs, instead of one fully-routed GDS. See
`native/legalize/README.md` for what these fixtures are used for and the
spike's own measured go/no-go result.

## What's here

| File | What it is |
| --- | --- |
| `<design>/<design>_gp.def.gz` | Frozen global-placement solution — captured immediately after `repair_design`/`repair_timing`, immediately before OpenROAD's own `detailed_placement` runs (the identical input both legalizers this spike compares start from). |
| `<design>/<design>_oracle_legal.def.gz` | OpenROAD's own `detailed_placement` result on that identical input — the oracle. |
| `<design>/<design>_gen_metrics.json` | Provenance (OpenROAD version, resolved PDK/liberty/LEF paths, seed) plus the `detailed_placement` Tcl command's own isolated wall-clock, in milliseconds. |
| `sky130_fd_sc_hd_tech.lef.gz` | The real `sky130_fd_sc_hd` tech LEF (`SITE`/layer definitions), shared by both designs. |
| `sky130_fd_sc_hd_cells_used.lef.gz` | The real `sky130_fd_sc_hd` cell LEF, **trimmed** to only the ~78 `MACRO` blocks either design's DEF actually references (`_filter_cell_lef.py`) — every retained block is byte-identical to the real upstream LEF; only unreferenced blocks are dropped, to keep this a small, reviewable diff (the full library LEF is ~1.4 MB; the trimmed, gzipped file is ~21 KB). |

Designs: `gcd` (`examples/functional-verification/gcd.v`, 454 placed
instances) and `modexp` (`examples/functional-verification/modexp.v`, 844
placed instances) — the same two designs
`docs/design/place-and-route-improvements-survey.md` §3.5's own
"Measurement plan" calls for ("a small corpus slice").

## Provenance

Generated by `regenerate.sh` — real Yosys (`klt synthesize`) + real
OpenROAD `26Q3-1080-gab6fd26351` (`openroad/orfs:latest` Docker image) +
a real volare-fetched `sky130A` (`open_pdks c6d73a35f524070e85faff4a6a9eef49553ebc2b`)
install, `sky130_fd_sc_hd`/`tt_025C_1v80`, `seed: 1`, the same
floorplan/IO/clock parameters `tests/corpus/place_and_route/regenerate.sh`
uses. Like that script, this is a **deliberate, reviewed** regeneration,
never a CI step — review the diff before committing a regenerated fixture.
