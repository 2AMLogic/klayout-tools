# `tests/corpus/sta/` — issue #809's STA-spike fixtures

Machine-generated, like `tests/corpus/legalize/` (see `../README.md`'s
"Legalizer-spike fixtures" section) — but a different pipeline stage: mapped
gate netlists (post-`write_verilog`, pre-placement), not placement DEF. See
`native/sta/README.md` for what these fixtures are used for and the
spike's own measured go/no-go result.

## What's here

| Path | What it is |
| --- | --- |
| `rtl/*.v` | Four hand-written RTL designs (`alu8`, `crc32`, `fifo16`, `mac16`), each written for this issue's corpus slice with a deliberately different critical-path shape — see each file's own header comment (wide mux-of-cones, shallow high-fanout XOR, control/mux-dominated, deep arithmetic carry chain). |
| `netlists/<design>_synth.v.gz` | The `write_verilog`-mapped netlist for each of the six designs in this slice — the four above, plus `gcd`/`modexp` (the repo's existing worked examples, `examples/functional-verification/*.v`, shared with `tests/corpus/legalize/`'s corpus). |
| `netlists/<design>.meta.json` | Provenance: `klt synthesize`'s own response fields (`instance_count`, `area_um2`, engine/version, deck content hash, PDK version). |
| `compare.py` | The three-way (native / wrapped-OpenSTA / today's-nothing) comparison harness — run this to reproduce every number in `native/sta/README.md`. |
| `regenerate.sh` | Regenerates the checked-in `netlists/*_synth.v.gz` + `.meta.json` fixtures. A **deliberate, reviewed** act, never a CI step — review the diff before committing a regenerated fixture. |

## Provenance

Generated by `regenerate.sh` — real Yosys (`klt synthesize`, engine
`0.68+post`) + a real volare-fetched `sky130A` install (`open_pdks
c6d73a35f524070e85faff4a6a9eef49553ebc2b`), `sky130_fd_sc_hd`/`tt_025C_1v80`,
no clock period constraint (this slice's comparison supplies its own
`--period` at compare time rather than baking one into the mapped netlist).
Unlike `tests/corpus/legalize/regenerate.sh` and
`tests/corpus/place_and_route/regenerate.sh`, this script needs **no**
OpenROAD/Docker and **no** PDK LEF — the comparison this spike runs is
netlist + liberty only, with no placement and no parasitics.
