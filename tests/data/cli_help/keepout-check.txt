usage: klt keepout-check [-h] --forbidden FORBIDDEN --margin MARGIN
                         [--cells CELL] [--region REGION] [--top TOP]
                         [--format {text,json}]
                         file

Assert that no shape on a forbidden layer set lies within a margin of a
guarded cell or region (a keep-out around a spiral inductor, a sensitive
analog block, ...) and report each intruding shape with its layer and
micrometre coordinates. The guard is the bounding box of every placement of
the --cells names and/or the --region window, sized outward by --margin; the
guarded cells' own shapes are never counted. Purely geometric; fully headless
via KLayout's batch database API. See docs/cli/keepout-check.md.

positional arguments:
  file                  path to a GDSII or OASIS layout file

options:
  -h, --help            show this help message and exit
  --forbidden, --layers FORBIDDEN
                        forbidden layer set as a path to a JSON file, or an
                        inline JSON array of [layer, datatype] pairs (e.g.
                        '[[67, 20]]'). Not validated by argparse -- an
                        empty/malformed value exits 1.
  --margin MARGIN       keep-out margin in micrometres (>= 0); a shape at
                        distance exactly the margin is clear. Not validated by
                        argparse -- a non-numeric or negative value exits 1.
  --cells CELL          repeatable exact cell name to guard (every placement
                        under each checked top cell, by bounding box). At
                        least one of --cells / --region is required.
  --region REGION       guarded window as an inline JSON array of four
                        micrometre coordinates [left, bottom, right, top]; may
                        be combined with --cells
  --top TOP             top cell to check when the stream has more than one;
                        omit to check every top cell
  --format {text,json}  output format (default: text)
