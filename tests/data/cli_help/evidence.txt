Evidence records around finished `klt sim` / `klt pex` runs. `record` wraps
the untouched report with git provenance, a dirty-inputs flag, pins and the
per-corner snapshot, never overwriting. `canonicalize` emits a report's
`--rerun` view.

positional arguments:
  <subcommand> record write one evidence-record/1 file lint lint the evidence-record/1 files under a repo claims check documents that cite evidence records against the records render fill marked tables in docs from evidence records canonicalize emit the view `--check ... --rerun` diffs, for committing

options:
  -h, --help show this help message and exit

--- klt evidence record ---

Write <root>/evidence/sim/<block>/<scope>/<YYYYMMDD>-<HHMMSS>-<short-sha>.json
(UTC time, git short SHA of --root) plus a <id>.d/ sidecar with per-corner
corner.cir and log copied from the report's artifacts. Exits 1 if the record
exists (no --force), --root is not a git work tree, or the wrapper metadata
would carry a local identifier.

positional arguments:
  report raw klt sim / klt pex JSON report (the -o file)

options:
  -h, --help show this help message and exit
  --request REQUEST request JSON the report was produced from
  --block BLOCK design under test
  --scope SCOPE evidence scope slug (e.g. full-pvt)
  --subset-reason SUBSET_REASON why this run is a subset of the full corner matrix
  --supersedes PATH an existing record this one supersedes (repeatable)
  --root ROOT git work tree the record is written into (default: cwd)
  --extensions FILE.json opaque JSON object stored verbatim under `extensions`
  --input PATH extra input (e.g. the netlist) included in the dirty_inputs check (repeatable)
  --format {text,json} output format (default: text)

--- klt evidence lint ---

Audit <root>/evidence/sim: record shape, id/filename, append-only history (git
diff vs --base), supersession chains, sidecar SHA-256s and re-derivation of
the klt sim verdict. Exits 0 clean, 1 on findings. --schema adds repo-specific
required fields, allowed extensions keys and a corner-id pattern.

positional arguments:
  root git work tree to lint (default: cwd)

options:
  -h, --help show this help message and exit
  --base BASE ref the append-only check diffs against (default: origin/main)
  --schema FILE.json flat declarative repo schema: required_fields, extension_keys, corner_id_pattern
  --no-append-only skip the git-diff append-only check (e.g. no base ref available)
  --format {text,json} output format (default: text)

--- klt evidence claims ---

Check documents against evidence records: every cited record exists (and its
JSON twin), a citation of a superseded record is an error unless under a <!--
klt:historical --> marker, and --registry rows must agree with the pointed-at
record values. Legacy records are resolved via the registry's `mapping` key.
Exits 0 clean, 1 on findings.

positional arguments:
  root repo root (default: cwd)

options:
  -h, --help show this help message and exit
  --docs GLOB [GLOB ...] document glob(s), relative to ROOT; a glob matching nothing is an error
  --registry FILE.json JSON registry: `claims` rows (literal, record, pointer, decimals, scale, corner, agg) and legacy- record `mapping`
  --format {text,json} output format (default: text)

--- klt evidence render ---

Rewrite <!-- klt:table id=NAME --> ... <!-- /klt:table --> blocks in --docs
from evidence records via a JSON --spec. Text outside blocks is untouched;
all-or-nothing. --check writes nothing and exits 1 if any block is stale.

positional arguments:
  root repo root (default: cwd)

options:
  -h, --help show this help message and exit
  --docs GLOB [GLOB ...] doc glob(s) relative to ROOT; each must match a file
  --spec FILE.json table spec, keyed by block id
  --check write nothing; exit 1 if any block is stale
  --format {text,json} output format (default: text)

--- klt evidence canonicalize ---

Emit a klt report reduced to exactly the fields `klt <kind> --check REPORT
--rerun` compares: run-scoped artifact paths and machine-local provenance
removed, verdict fields untouched, keys sorted. Commit this instead of hand-
maintaining a copy of the exclusion list (issue #5541). Two canonical views of
one kind compare equal exactly when --rerun reports no drift. REPORT is a path
or `-` for stdin. Caveat: `klt lvs --rerun` also tolerates fields the
committed report never carried, which depends on the pair and cannot be
expressed on one report -- see docs/cli/evidence.md.

positional arguments:
  REPORT klt --format json report, or `-` for stdin

options:
  -h, --help show this help message and exit
  --kind {drc,lvs,erc,extract,synthesize,place-and-route,equiv} which verb produced REPORT (a report does not name its own verb)
  --format {json,text} output format (default: json -- the canonical report itself)
