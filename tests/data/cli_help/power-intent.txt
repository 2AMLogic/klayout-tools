Check the power intent of a flat gate-level Verilog netlist with a power-gated
domain against a JSON intent file: every gated-domain output passes a clamp
cell with the declared value, every state element is retained or gated (and a
retained one is not fed by the gated domain un-isolated), and the declared
control-event sequence is correctly ordered. Any violation fails (exit 3).
Read-only, headless. See docs/cli/power-intent.md.

positional arguments:
  netlist path to a flat gate-level Verilog netlist

options:
  -h, --help show this help message and exit
  --intent FILE JSON power-intent file
  --cell-models FILE PDK functional Verilog cell-model file (repeatable)
  --top TOP top module (required when the netlist has several)
  --format {text,json} output format (default: text)
