Write one request per corners.process entry plus the shard manifest for `klt
sim-merge`, next to the source request. The manifest's corner ids come from
the same expansion `klt sim` runs. Monte Carlo and deck-list requests are
refused. See docs/cli/sim.md 'Planning shards'.

positional arguments:
  request               klt sim request JSON to split

options:
  -h, --help            show this help message and exit
  --axis {process}      axis to shard by (default: process)
  --format {text,json}  output format (default: text)
