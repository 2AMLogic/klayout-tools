Compare two layout streams shape-for-shape. Ignores stream timestamps, element
order and library name; never ignores coordinates, path widths, text, instance
transforms, the database unit or cell names. With --flattened, compares the
instantiated geometry instead (per-layer XOR, drawn layer set, bounding box,
labels) and ignores cell names and hierarchy. Exit 0 = equivalent, 3 = layouts
differ, 1 = unreadable file or unknown --top.

positional arguments:
  file_a first GDSII or OASIS layout file
  file_b second GDSII or OASIS layout file

options:
  -h, --help show this help message and exit
  --top TOP compare only this cell's hierarchy (must exist in both streams)
  --max-items MAX_ITEMS cap on listed differences per list (counts stay exact; default 50)
  --flattened compare the flattened (instance-placed) geometry, bounding box and labels instead of the cell-by-cell content: cell names and hierarchy partitioning are ignored
  --format {text,json} output format (default: text)
