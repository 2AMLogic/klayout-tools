Emit a parallel-prefix adder as Verilog RTL from a named architecture
(`ripple`, `brent-kung`, `han-carlson`, `sklansky`, `kogge-stone`) or from an
explicit N x N binary cell map -- issue #1722, the arithmetic-architecture
lever for `klt synthesize`. Pure Python string generation: no Yosys, no PDK,
no engine. Writes five files next to each other: the structural adder, a
behavioural `a + b + cin` reference with identical ports, a self-checking
testbench, a Yosys `techmap -map` rule file substituting the adder for `$add`
cells of the same width, and a ready-to-run `klt equiv` request pairing the
reference (gold) against the adder (gate) -- so proving the emitted Verilog
correct is one follow-up command. Deliberately NOT named `klt gen-arith`/`klt
gen ...`: `klt gen` is the layout/PCell generator family, and this emits RTL.
See docs/cli/arith-gen.md.

options:
  -h, --help show this help message and exit
  --width WIDTH adder width in bits (required with --arch; with --cell-map the width comes from the matrix and this flag, if given, must match)
  --arch {ripple,brent-kung,han-carlson,sklansky,kogge-stone} prefix-adder architecture to build the cell map from. Mutually exclusive with --cell-map.
  --cell-map CELL_MAP path to a JSON file holding the N x N cell map -- either a bare matrix of 0/1 entries or an object with a `cell_map` key (the shape `--format json --include- cell-map` emits, so a payload round-trips). Mutually exclusive with --arch.
  --module-name MODULE_NAME Verilog module name for the generated adder (default: klt_add_<architecture>_<width>)
  --output-dir OUTPUT_DIR directory to write the generated files into (default: cwd)
  --include-cell-map include the full N x N cell map in the output (the `cell_map` field under --format json, an ASCII matrix under --format text); omitted by default because it is O(N^2)
  --format {text,json} output format (default: text)
